# CodeAlpha Basic Chatbot (AlphaBot)

An interactive, rule-based desktop chatbot developed in Python using Tkinter as part of the CodeAlpha Python Programming Internship.

## Features
- **Conversational Rules:** Intelligent keyword matching for greetings, health inquiries, and identity questions.
- **System Utilities:** Real-time retrieval of live system time and date.
- **Arithmetic Engine:** Built-in expression evaluation for quick math calculations.
- **Modern GUI:** Clean desktop messaging interface with dynamic scrolling and role-based chat bubbles.

## Key Concepts Used
- Conditional Logic (`if-elif-else`)
- Functions & Modular Architecture
- String Parsing & Substring Matching
- Desktop GUI Development (`tkinter`)

python app.py
